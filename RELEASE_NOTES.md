## LocalDockerServer v1.0.1

### Русский
Автоматическое скрытие панели логов запуска после успешного старта сервера.

- **Установщик macOS:** `LocalDockerServer.dmg`
- **Архив для автообновления / распаковки:** `LocalDockerServer-macOS.zip`

### English
Automatically hide the startup log drawer once the server finishes starting.
